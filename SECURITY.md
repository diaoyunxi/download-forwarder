# Security Policy

## Supported Versions

Only the latest release and the current `main`/`master` branch receive security updates.

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

If you discover a security issue in this project, please report it responsibly:

1. Go to the repository → **Security** → **Report a vulnerability**
2. Provide a clear description of the issue, including steps to reproduce
3. We will acknowledge receipt within 72 hours
4. We will work with you to understand and address the issue
5. Once resolved, we will publish a security advisory

Thank you for helping keep this project safe.
